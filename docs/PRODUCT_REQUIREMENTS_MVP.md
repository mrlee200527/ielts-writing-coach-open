# 雅思作文助手第一版 MVP 产品需求

- 状态：已由总指挥确认
- 日期：2026-08-13（北京时间）
- 产品角色：写作过程中的克制型 AI Coach
- 核心范围：IELTS Academic Writing Task 1，覆盖动态、静态、流程图和地图

## 1. 产品目标

帮助学生在独立完成 Task 1 的过程中，及时发现少量真正影响表达、任务完成和目标分数的问题，并在提交后明确下一次练习重点。第一版不追求“指出所有错误”，也不以生成范文或代写作为价值。

成功体验是：学生能够完成自己的作文；写作过程没有被频繁打断；每次只处理最值得处理的问题；多次写作后能感知自己的稳定弱项与进步。

## 2. 目标用户

核心用户为正在备考 IELTS Academic Writing Task 1、目标分数约 5.5–7.0 的自学学生。他们已了解基础作文结构，但常见困难包括：

1. 写作时无法判断哪些语言错误会影响理解或分数；
2. 能描述数据，却不会筛选主特征、组织比较和支持结论；
3. 收到大量批改后，不知道下一篇最该练什么。

第一版不以零基础英语学习者、教师课堂管理用户或 7.5+ 精修用户为核心人群。

## 3. 产品原则

1. **克制优先**：高价值、高置信度且时机合适才主动提示；允许检查后不展示反馈。
2. **学生执笔**：先指出问题和方向，默认不自动修改、不生成整段或全文。
3. **分阶段反馈**：句子阶段处理必要的语言问题，段落阶段处理组织与任务完成，全文阶段评分总结。
4. **不确定性透明**：题图不清时说明影响，不把不确定事实作为批评学生的依据。
5. **长期证据优先**：一次失误不定义学生；长期学习结论必须来自多篇已完成作文。

## 4. 完整用户流程

1. 用户进入首页，选择“开始 Task 1 写作”。
2. 用户上传题图，可补充或粘贴题目文字。
3. 系统自动识别题型与图表内容；用户始终可查看原题图。
4. 识别完成后进入写作工作台：题目与原图、编辑区、当前高价值反馈。
5. 用户自由写作，不强制使用固定模板或段落顺序。
6. 句子完成后系统静默检查，必要时展示一条轻量语言反馈。
7. 段落完成后系统检查段落功能、主旨、比较、数据支持和衔接，必要时展示少量提示。
8. 用户可以修改、展开提示或忽略提示；处理反馈不是继续写作的前置条件。
9. 达到 150 词后可正常提交；不足 150 词时提示风险，但允许继续提交。
10. 提交后冻结本次作文版本，生成四维评分、证据与下一步练习。
11. 已完成作文作为学习档案证据，影响未来提示优先级。

写作阶段不展示持续变化的预测分数或完整学习档案，避免分散注意力。评分与长期总结集中在提交后呈现。

## 5. 反馈触发与展示规则

### 5.1 句子完成

出现以下任一行为，视为候选句子完成：输入句末标点后停顿约 1.5 秒、光标离开当前句、换行并开始下一句。若用户继续编辑该句，尚未展示的检查结果失效。

句子阶段只主动提示高置信度且影响理解、基本准确性或目标分数的问题。风格升级、同义词替换和轻微表达优化延迟到段落或全文阶段。

### 5.2 段落完成

出现以下任一行为，视为候选段落完成：连续输入两个换行、光标离开该段并开始下一段、用户点击“检查本段”。自动触发等待约 3 秒；明显未完成的短段落不立即评价。

段落阶段检查该段的功能、中心信息、关键比较、数据或特征支持、衔接及明显遗漏。

### 5.3 反馈预算

- 任一时刻最多展示 1 条句子反馈；同一段落最多展示 2 条主动反馈。
- 新反馈不得堆叠覆盖用户尚未处理的反馈；低优先级问题延迟或抑制。
- 同一问题在同一作文中不重复提醒。
- 用户连续忽略两次同类主动提示后，本篇作文不再主动展示该类提示。
- 未发现高价值问题时保持安静，仅以非弹窗状态表明检查已完成。

## 6. 不同问题的帮助程度

### 6.1 拼写

标出疑似拼错词，可展示 1–3 个候选词；不自动替换。仅大小写或输入习惯问题不反复提醒。

### 6.2 语法

指出问题位置、影响和规则方向，优先用简短问题引导。只有用户主动展开反馈时，才提供局部修改示例；不默认重写整个句子。

### 6.3 结构与任务完成

指出缺失或薄弱的段落功能、总体概述、比较、数据证据或衔接，并提出一个可行动的思考问题。不得生成整段、固定模板或可直接复制的答案。

## 7. 题图识别不确定体验

用户始终看到原题图。存在识别不确定时，页面显示：

> 部分图表信息可能未被准确识别。你可以继续写作；相关反馈和评分将减少对这些细节的判断。

页面用通俗类别说明不确定项，例如“部分数据标签不清晰”“流程箭头关系不确定”或“地图方位关系不确定”，不展示内部置信度数字。系统不得基于不确定事实判定学生描述错误；提交后需标明哪些评分结论受到影响。

## 8. 全文评分页面

评分页面展示：

1. 按 0.5 band 呈现的总分估计，并明确标注“非官方成绩”；
2. Task Achievement、Coherence and Cohesion、Lexical Resource、Grammatical Range and Accuracy 四项分数；
3. 每项 1 条有作文证据支持的优点，以及最多 2 条主要问题；
4. 全文唯一的“最优先改进项”，说明其影响；
5. 2–3 个可执行的后续练习；
6. 字数、用时、提交正文和本次已展示反馈；
7. 题图识别不确定时，受影响的评分维度与较低确定性说明。

第一版不展示伪精确概率、复杂雷达图、整篇范文改写或大量同类例句。

## 9. Student Memory 用户体验

面向用户统一称为“学习档案”，包含：

- **高频问题**：同类问题至少在两篇已完成作文中有证据后显示；
- **正在进步**：近期错误频率下降或能力表现持续改善；
- **已掌握**：经过多篇作文验证的稳定能力；
- **下一篇重点**：最多 1–2 项，并影响下一篇提示优先级。

每条学习记录可查看来自哪些已完成作文，用户可删除。单篇作文的一次问题只作为证据，不立即形成长期标签。

## 10. MVP 范围

### 10.1 必须完成

- 四类 Academic Task 1 题图上传、题目文字补充与自动识别；
- 题图识别不确定状态及降级体验；
- 写作工作台、自动保存、字数和用时；
- 句子完成检测与克制型语言反馈；
- 段落完成检测与结构、比较、数据使用反馈；
- 反馈预算、去重、忽略与过期控制；
- 主动提交、字数风险提示与四维评分页面；
- 基于已完成作文证据的基础学习档案；
- 用户查看和删除作文及学习记录。

### 10.2 明确延期

- IELTS Writing Task 2；
- 教师后台、班级与多人协作；
- 教师视频知识库正式接入；
- 范文生成、整段或全文代写；
- 模拟考试监考模式；
- 语音辅导与开放式聊天问答；
- 社区、课程、支付与排行榜；
- 高级趋势图、复杂个性化课程与原生移动应用。

## 11. Acceptance Criteria

### AC-01 开始写作与题目导入

- Given 用户进入首页，When 选择“开始 Task 1 写作”，Then 能上传一张题图并可选填题目文字。
- Given 上传成功，When 题图仍在识别，Then 用户能看到原图和明确的处理中状态，不会看到伪造的识别结果。
- Given 题图属于四类支持题型之一，When 识别结束，Then 用户可进入写作工作台并看到题目、原图和空白编辑区。

### AC-02 题图识别不确定

- Given 存在不确定数据标签、步骤或方位，When 进入工作台，Then 显示通俗的不确定性说明且不显示内部置信度数字。
- Given 某事实被标记为不确定，When 生成反馈或评分，Then 不得以该事实为唯一依据判定学生写错。
- Given 识别无法得到可用结果，When 用户继续写作，Then 编辑、保存和提交仍然可用，并说明相关评价会受限。

### AC-03 写作工作台与保存

- Given 用户正在写作，When 正文、字数或用时发生变化，Then 页面持续显示最新字数和用时，且无需等待 AI 检查。
- Given 用户离开后重新进入未提交作文，When 恢复会话，Then 能看到最近一次成功保存的正文。
- Given AI 检查失败，When 用户继续输入或提交，Then 写作、保存和提交不被阻断。

### AC-04 句子完成检测

- Given 用户输入句末标点后停顿约 1.5 秒、离开当前句或开始下一句，When 当前句保持不变，Then 系统启动一次句子检查。
- Given 用户在结果出现前修改该句，When 旧结果返回，Then 旧反馈不展示。
- Given 句子没有高价值问题，When 检查结束，Then 不弹出反馈，仅提供非打断式已检查状态。

### AC-05 句子级帮助

- Given 存在高置信度拼写问题，When 展示反馈，Then 标出疑似词并最多提供 3 个候选词，不自动替换。
- Given 存在高价值语法问题，When 展示默认反馈，Then 指出位置和规则方向，但不直接重写整句。
- Given 用户主动展开语法反馈，When 请求更多帮助，Then 可看到局部修改示例。

### AC-06 段落完成检测与反馈

- Given 用户开始下一段、离开本段或点击“检查本段”，When 自动触发条件稳定约 3 秒，Then 检查本段功能、比较、证据和衔接。
- Given 段落明显未完成且用户未主动检查，When 短暂停顿，Then 不主动展示结构评价。
- Given 段落存在多个问题，When 返回结果，Then 最多主动展示 2 条最高价值反馈，且不生成整段答案。

### AC-07 反馈预算与防依赖

- Given 页面已有一条句子反馈，When 新句子检查完成，Then 不同时叠加第二条句子反馈。
- Given 同一问题已经提示，When 后续检查再次发现相同问题，Then 本篇作文不重复主动提醒。
- Given 用户连续两次忽略同类反馈，When 再次发现该类问题，Then 本篇作文不再主动展示该类反馈。
- Given 用户不处理反馈，When 继续写作，Then 系统不阻止编辑、换段或提交。

### AC-08 提交与字数风险

- Given 正文少于 150 词，When 用户点击提交，Then 显示字数风险并允许用户返回继续写或确认提交。
- Given 用户确认提交，When 评分开始，Then 本次评分绑定已提交正文，后续草稿变化不改变该结果。
- Given 评分暂时失败，When 用户查看作文，Then 仍可读取已提交正文并看到可理解的重试状态。

### AC-09 全文评分

- Given 评分完成，When 用户进入结果页，Then 看到总分估计、非官方声明和四项评分。
- Given 任一维度有评分，When 展开该维度，Then 看到 1 条作文证据支持的优点及最多 2 条主要问题。
- Given 全文存在多个弱项，When 展示总结，Then 只标记 1 个最优先改进项，并提供 2–3 个具体练习。
- Given 题图识别存在不确定，When 展示评分，Then 明确标出受影响维度和结论限制。

### AC-10 学习档案

- Given 某问题只在一篇已完成作文出现，When 用户查看学习档案，Then 该问题不显示为“高频问题”。
- Given 同类问题至少在两篇已完成作文中有证据，When 更新学习档案，Then 可显示该问题并可查看证据来源。
- Given 系统识别到稳定改善或掌握，When 展示学习档案，Then 使用“正在进步”或“已掌握”状态，而不是永久保留负面标签。
- Given 用户删除一条学习记录，When 再次查看学习档案，Then 该记录不再显示或影响后续提示优先级。
- Given 用户开始下一篇作文，When 系统使用学习档案，Then “下一篇重点”最多为 2 项。

### AC-11 数据自主权

- Given 用户查看历史作文，When 选择删除并确认，Then 该作文不再出现在用户可见历史中。
- Given 用户查看学习档案，When 查看任一长期结论，Then 能看到该结论的作文证据来源并可删除该结论。

## 12. 产品验收边界

MVP 验收以完整主链路可用和克制型干预规则成立为准，不以“发现所有错误”或“评分等同官方考官”为标准。任何新增功能若增加实时反馈密度、允许整段代写或把一次问题固化为长期标签，均视为超出本版产品边界。

## 13. 交接给架构 AI 的待确认事项

架构 AI 需基于本 PRD 确认以下产品规则能否被稳定支持，并报告任何偏差，不得自行改变验收标准：

1. 句末停顿约 1.5 秒、段落稳定约 3 秒与正文版本变化之间的事件和失效边界；
2. “任一时刻 1 条句子反馈、每段最多 2 条反馈、连续忽略两次后抑制”的状态边界与跨刷新连续性；
3. 四类题图的不确定项如何贯穿段落反馈和全文评分，确保不确定事实不成为唯一扣分依据；
4. “不足 150 词仍允许提交”的冻结版本、风险确认与评分状态边界；
5. 学习档案“至少两篇作文形成高频问题”的证据计数、删除影响及状态迁移边界；
6. 用户删除作文或学习记录后，相关证据、评分和后续个性化之间的一致性要求；
7. 写作阶段隐藏预测分数和完整学习档案后，现有三栏原型的信息层级调整方案；
8. 上述行为的可观测事件和测试接口，以便测试 AI 验证触发、抑制、过期和降级规则。

下一责任 AI：架构 AI。架构确认后，由测试 AI依据 Acceptance Criteria 先形成验收用例，再由程序员 AI 制定实现计划。
